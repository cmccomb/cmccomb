### MATLAB tools

- [rand_index](https://github.com/cmccomb/rand_index): compare two cluster assignments with the Rand or adjusted Rand index.
- [gplot3](https://github.com/cmccomb/gplot3): draw adjacency-matrix graphs in three dimensions.
- [break_axis](https://github.com/cmccomb/break_axis): add a visual axis-break mark to a plot (without changing its data or scale).

Each repository includes a usage example, tests, and a link to its MATLAB File Exchange listing.
